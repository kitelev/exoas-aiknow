# Retrieval: все концепты с метками и алиасами (проекция Stage A)

Запрос-источник проекции словаря концептов для офлайн-извлечения концептов из промпта (RFC 9d5ffe26 v3, §Архитектура п. 2, фаза 2 программы 204e2439). Зовёт генератор `~/.claude/hooks/lib/build-concepts-index.py`: `exocortex-cli run-query <uid> --vault /Users/kitelev/vaults/vault-exodev --format json` (по полному vault-exodev — здесь смонтированы все ассетспейсы с концептами; 5–40 с, поэтому вызов редкий — пересборка `~/.cache/exocortex/concepts-index.json` по факту правки словаря, не на каждый промпт). Параметров нет.

Выход — строки `(c, uid, label, alias, created)`: `c` — file-IRI концепта (путь внутри vault даёт ассетспейс), `uid` — `exo__Asset_uid` (quoted-литерал; у концепта без `exo__Asset_uid` не связан — генератор берёт stem имени файла, если он UUID), `label` — `exo__Asset_label` (quoted-литерал; у концепта с parseable-меткой вида `prefix__Name` движок эмитит symbolic IRI `…/ontology/<prefix>#<Name>` — генератор берёт локальное имя после `#`), `alias` — по одной строке на каждое значение `aliases` (движок эмитит `exo#Asset_aliases`), `created` — `exo__Asset_createdAt` (для выбора каноничного UID среди двойников).

Класс фильтруется точным локальным именем `STRENDS(STR(?k), "concept#Concept")`, а не `CONTAINS`: подстрока `concept#Concept` матчит также `concept#ConceptDefinition`, `concept#ConceptDefinitionKind`, `concept#ConceptDefinitionSpec` (замер 2026-09-14 на vault-exodev: 2 835 субъектов по `CONTAINS` = 2 826 по `STRENDS` + 9 инстансов трёх соседних классов; оба `COUNT(DISTINCT ?c)` сняты `query --no-cache`). Число строк больше числа концептов (по строке на алиас) — считать концепты по `COUNT(DISTINCT ?c)`.

⛤ **Депрекированные концепты исключены (2026-09-14, тикет 31828452 — дедуп словаря).** Слитый дубль получает `exo__Asset_deprecatedBy` → канон, его алиасы переносятся на канон, входящие перецеливаются; в проекции он больше не нужен — иначе те же алиасы вели бы на два UID и группа-двойник не исчезала бы. Фильтр — `FILTER NOT EXISTS { ?c exo:Asset_deprecatedBy ?dep }` (корреляция triple-pattern'ом, без внутреннего FILTER по внешней переменной). Замер при введении: 3 179 концептов всего = 3 174 без deprecated + 5 с `deprecatedBy` (`query --no-cache`, оба счёта `COUNT(DISTINCT ?c)`).

```sparql
PREFIX exo: <https://exocortex.my/ontology/exo#>
SELECT ?c ?uid ?label ?alias ?created WHERE {
  ?c exo:Instance_class ?k .
  FILTER(STRENDS(STR(?k), "concept#Concept"))
  OPTIONAL { ?c exo:Asset_uid ?uid }
  OPTIONAL { ?c exo:Asset_label ?label }
  OPTIONAL { ?c exo:Asset_aliases ?alias }
  OPTIONAL { ?c exo:Asset_createdAt ?created }
  FILTER NOT EXISTS { ?c exo:Asset_deprecatedBy ?dep }
}
ORDER BY ?c
```
