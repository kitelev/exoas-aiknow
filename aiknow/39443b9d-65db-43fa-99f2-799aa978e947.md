# Спавн дочерней сессии: baseline-флор в СОТНЯХ ТЫСЯЧ токенов ⇒ ТОЛЬКО `[1m]`-модели

Регрессия по **54** историческим сессиям одного проекта (транскрипты × размер корпуса из `git log` dotfiles), **R² = 0.99**; на контрольной сессии ошибка **+0.4 %** (607 406 против факта 604 997). ⛔ Вход — ТОЛЬКО файлы БЕЗ `paths:`; подставив весь `rules/`, завысишь на размер условных. ⛤ Свободный член 90 706 = ВСЁ остальное (сис.промпт, схемы 14 top-level тулов, листинг скиллов/агентов, оба `CLAUDE.md`, `MEMORY.md`) ⇒ **корпус правил — 85 % префикса**, а не «правила плюс сопоставимый харнесс».

## Принцип

Дочерняя Claude-сессия в этом окружении загружает **весь baseline-корпус** до первого полезного хода: `~/dotfiles/.claude/rules/*` (1.73 МБ на 2026-09-06, из них always-on — весь этот объём; условные `paths:` ещё 133 КБ вне флора) + `~/.claude/CLAUDE.md` (~26 КБ) + project-`CLAUDE.md` + скиллы + memory-индекс. Замер 2026-07-30 давал ≈545K; ⛔ он УСТАРЕЛ — см. пере-замеры §A2 (753K, затем ~830K).

⛔ Следствие: **bare-контекстный вариант модели (200K) для спавна непригоден ФИЗИЧЕСКИ**, а не «тесновато». Сессия стартует на «100% context used», немедленно уходит в компакцию с нулевого хода и жжёт деньги до первого tool-call. Единственный рабочий вариант — **`[1m]`-суффикс** (`claude-opus-5[1m]`). **Цена та же** ($5/$25 за MTok — 1M-контекст у Opus 5 без long-context premium), т.е. экономии от bare-варианта нет вообще: он просто не работает.

**Варьировать между фазами/детьми можно ТОЛЬКО `effort`**, не размер контекста.

## Когда правило срабатывает

- Составление модельной матрицы в orchestrator/meta-промпте («Phase 1 → модель X, Phase 2 → модель Y»).
- Любой `/spawn-nested-claude` / `spawn-session.sh` / `cs`-спавн.
- Соблазн «для простой фазы возьму модель попроще/подешевле» — для **контекста** это не работает; берётся effort.

## Что делать

```
✅ claude-opus-5[1m]   / effort: high|xhigh   ← единственный рабочий класс для детей
⛔ claude-opus-5       (bare, 200K)           ← сгорит на orientation
⛔ claude-sonnet-5     (bare)                 ← тот же порог
```

- Матрица в промпте варьирует **effort**, а не суффикс контекста.
- Появилась новая модель → сперва сверить её контекст с **актуальным** размером baseline-корпуса (он растёт с каждым новым rule-файлом), а не полагаться на «обычно хватает».
- Замер корпуса при сомнении:
  ```bash
  du -sk ~/dotfiles/.claude/rules ~/.claude/CLAUDE.md ~/dotfiles/.claude/skills 2>/dev/null
  # грубая оценка: 1 КБ русского markdown ≈ 250-400 токенов
  ```

## Детект сгоревшего спавна (первые 60-90 с)

`tmux capture-pane` показывает **«100% context used» / немедленную компакцию** при нулевом внутреннем `PROGRESS:STARTED` → это НЕ spawn-race (R4) и НЕ rate-limit stall, а **context-floor**. Recovery: kill + респавн на `[1m]`; ретраить ту же модель бессмысленно (детерминированно).
