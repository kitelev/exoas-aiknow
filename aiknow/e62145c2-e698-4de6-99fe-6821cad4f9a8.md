Симптом: `git diff > patch` перед сносом worktree даёт пустой файл (rc=0), потому что правки уже застейджены — `git diff` без аргументов показывает только неиндексированное. Спасать работу — `git diff HEAD` и проверять `[ -s patch ]`; ветка при этом выживает, но указывает на коммит без правок.
