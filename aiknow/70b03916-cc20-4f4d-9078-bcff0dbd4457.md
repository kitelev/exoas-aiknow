Симптом: при rapid bulk (`git/trees` POST, десятки запросов подряд) GitHub отвечает 403 secondary rate-limit, хотя `gh api rate_limit` показывает полный core — это другой лимит (CPU-time, не объём контента), и «не ждать core-reset» к нему неприменимо. Движок с v16.195.0 честно ждёт `Retry-After`.
