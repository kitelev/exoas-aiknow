# PR auto-merge chicken-egg deadlock

## Принцип

When a PR **implements a policy that would prevent its own CI failures**, the standard auto-merge pattern enters chicken-egg deadlock:
- Auto-merge gated by CI green
- CI fails on conditions the PR fixes
- Policy не applied until merge
- → infinite stuck PR

Recognize early; choose explicit unblock pattern rather than waiting indefinitely.

## Когда правило срабатывает

Combination of all:
1. PR implements CI/test/release policy (retries policy, flake handling, lint relaxation, timeout adjustment, etc.)
2. PR's own CI run hits the exact failure mode the policy mitigates
3. Auto-merge enabled but CI never goes green
4. No reasonable expectation that subsequent reruns will fix (failure is systemic, not transient)

## Detection signals

- PR open ≥30 min с consistent 2+ failed checks despite reruns
- Failed checks match exact patterns в PR body acceptance criteria
- Test/CI infrastructure PRs touching `*.config.{ts,js}`, `retries`, `timeout`, `playwright.*`, `pytest.ini`, etc.
- "Это применится после merge" rationalization в PR description

## Mitigation options (ranked by safety)

### Option A — Bootstrap commit (safest)

Add ONE-OFF commit к PR that applies the policy temporarily directly to failing specs:
- For @flaky-track retries policy → add `retries: 1` directly в failing spec's `describe.configure`
- This makes CI green WITHOUT depending on the policy infrastructure
- Subsequent commit reverts the spec-level override, relies on policy infrastructure
- Merge happens normally

### Option B — Admin merge override (requires permissions)

If user has admin rights:
```bash
gh pr merge <N> --admin --squash
```
Bypasses required-checks-must-pass branch protection. Use only when:
- Reviewers approved
- Failing checks ARE the chicken-egg case (not real bugs)
- Document admin override в merge commit / PR description

### Option C — Temporary spec skip + follow-up

Skip the failing specs via `.skip` / `xfail` in this PR, file follow-up issue к remove skip after policy live. Risk: skip может forgotten.

### Option D — Defer (default for autonomous mode)

If unsure → defer to human review. Document deadlock в state file. Don't admin-merge autonomously.

## Anti-patterns

- ⛔ Repeated `gh run rerun --failed` hoping fluke pass — wastes CI minutes, never works for systemic chicken-egg
- ⛔ Admin merge without documented rationale в commit message — future audit confusion
- ⛔ Ignore deadlock + hope it resolves — PR stays OPEN indefinitely, blocks downstream
- ⛔ Spawning child to "investigate" when failure is structural not behavioral
