# Retrieval: правила по концептам промпта (`$concepts`, `$rules`)

Несущий запрос графового пути retrieval правил (RFC 9d5ffe26 v3, §Архитектура п. 1; фаза 1 программы 204e2439). Зовёт хук `rules-symptom-retrieval` при `RSR_SOURCE=graph` (фаза 4) и — как временный второй слой — модель через Gate 0 (`/context-loader`, `/knowledge-search`): `exocortex-cli run-query <uid> --vault <узкий mount exoas-aiknow> --format json --param concepts=<UID концептов через запятую> --param rules=<UID тел реестра rules-graph-pilot.json через запятую>`.

Параметры подставляются `NamedQueryRunner` экранированными строковыми литералами: `$concepts` — список UID концептов промпта, `$rules` — список UID тел правил реестра (88 UID ≈ 3 255 символов, проходит через argv). Оба фильтра — `CONTAINS` по литералу-списку.

Выход — строки `(rule, label, concept, fanout)`: `rule` — IRI тела правила, `label` — его метка, `concept` — UID концепта (или локальное имя при symbolic-форме объекта), `fanout` — число правил РЕЕСТРА, связанных с этим концептом (подзапрос с тем же фильтром `$rules` внутри — иначе fan-out считался бы по всем субъектам ассетспейса, ревью v3 находка №1: 3 против 1). Логарифм `gain = log2(M / fanout)` считает вызывающий код — `LOG()` движок не парсит.

Форма объекта ребра `aiKnow__Memory_aboutConcept` снимается двумя ветвями `BIND`: file-IRI с путём (vault-exodev) и беспутевая (узкий mount, концепты не смонтированы) — хвост `<uid>.md`; symbolic-форма `…/ontology/concept#<Local>` (если концепт получит parseable-метку) — хвост после `#`. Пустой `$rules` даёт 0 строк: вызывающий обязан отказывать на пустом реестре, а не читать пустую выдачу как «правил нет».

```sparql
PREFIX aiKnow: <https://exocortex.my/ontology/aiKnow#>
PREFIX exo: <https://exocortex.my/ontology/exo#>
SELECT ?rule ?label ?concept ?fanout WHERE {
  ?rule aiKnow:Memory_aboutConcept ?c .
  ?rule exo:Asset_uid ?ru .
  ?rule exo:Asset_label ?label .
  BIND(IF(CONTAINS(STR(?c), "#"),
          REPLACE(STR(?c), "^.*#", ""),
          REPLACE(STR(?c), "^.*/([^/]+)\\.md$", "$1")) AS ?concept)
  FILTER(CONTAINS($concepts, ?concept))
  FILTER(CONTAINS($rules, STR(?ru)))
  {
    SELECT ?c (COUNT(DISTINCT ?r) AS ?fanout) WHERE {
      ?r aiKnow:Memory_aboutConcept ?c .
      ?r exo:Asset_uid ?rr .
      FILTER(CONTAINS($rules, STR(?rr)))
    } GROUP BY ?c
  }
}
ORDER BY ?rule
```
